PM E2 - Roles at access control (PM Scheduler)
==============================================

TERMINAL (PowerShell) sa project folder, hal. C:\laragon\www\school-maintenance-system:

  cd C:\laragon\www\school-maintenance-system
  git add -A ; git commit -m "Before PM E2 access control"
  tar -xf "$env:USERPROFILE\Downloads\pm-e2-access-patch.zip" -C .
  php artisan config:clear
  php artisan view:clear
  php artisan test --filter=PmAccessTest
  php artisan test

DI MO MA-EXTRACT ANG ZIP? Gamitin ang terminal (piliin ang isa), sa loob ng project folder:
  A) tar -xf "$env:USERPROFILE\Downloads\pm-e2-access-patch.zip" -C .
  B) Expand-Archive -Path "$env:USERPROFILE\Downloads\pm-e2-access-patch.zip" -DestinationPath . -Force

WALANG MIGRATION. WALANG "npm install". WALANG "npm run build".

I-PUSH SA GITHUB (kapag pasado na ang test):
  git status
  git add -A
  git commit -m "PM E2: read-only PM access (view_pm_schedules, view_pm_reports)"
  git push
  (Kung "no upstream branch": git push -u origin main   -- palitan ang main kung iba ang branch: git branch --show-current)

ANO ANG NAGAWA
  Dalawang bagong capability sa config/permissions.php:
    view_pm_schedules  = tumingin LANG: PM schedules, Equipment, History, calendar feed
    view_pm_reports    = PM compliance report (gagamitin sa E3)
  manage_pm_schedules (Maintenance Admin) ay kasama na ang pagtingin.

  Default (CONFIRM WITH CLIENT, nasa docs/OPEN_QUESTIONS.md #67-69):
    Maintenance Admin : tumingin + magbago + PM report
    President         : tumingin lang + PM report
    Finance           : PM report lang (HINDI ang schedules / calendar)
    Custodian, Requester, Dept Head, Treasurer : wala (403)
  Para palitan: i-edit lang ang config/permissions.php, walang code na gagalawin.

  Ang mga pahinang nagbabago ng data (create, edit, toggle, delete, "Ticket now", bulk, duplicate, equipment add / edit / delete)
  ay Maintenance Admin pa rin lang. 403 din ang sagot ng server kahit manual na i-send ng President.
  Ang President ay nakakakita ng mga pahina na WALANG buttons na nagbabago (may note na "You can look ... but not change").
