Paano gumagana ang viewer:
  I-click ang pangalan ng file sa Attachments o sa conversation -> bubukas ang pop-up.
  - Larawan (JPG/PNG/WebP): may zoom (+ / - / 100% na button, double-click, Ctrl+wheel, o ang keys + - 0).
  - PDF: nasa loob ng pop-up (ang zoom ay galing sa PDF viewer ng browser). Sa iPhone, gamitin ang "New tab".
  - Word (.docx): simplified na TEXT preview (walang formatting/larawan/table layout), may zoom ng laki ng letra.
  - Excel (.xlsx) at iba pa: walang preview; may Download button.
  - Prev / Next (o ang arrow keys ← →) ay naglalakad sa lahat ng file sa page, ayon sa ayos nila sa page.
  - Esc o click sa madilim na gilid = isara. Ctrl/Cmd/Shift+click = bubukas pa rin sa bagong tab gaya ng dati.
  Bawat file na ipinakita ay naka-log sa Audit log bilang "Opened" / "Previewed" (gaya ng dati).

Remove:
  Lumalabas ang "Remove" (sa listahan at sa pop-up) LANG sa taong pinapayagan ng RequestAttachmentPolicy:
    - Maintenance Admin (may add_attachment) -> kahit anong file ng ticket na nakikita niya
    - ang nag-upload ng file -> habang HINDI pa Closed/Disapproved ang ticket
    - file sa loob ng internal note -> staff lang na nakakabasa ng internal notes
  May confirm bago mag-delete. Binubura ang row at ang mismong file sa private storage.
  Naka-log:
    - Audit log: action "attachment_deleted" (sino, ticket, pangalan ng file, uri, laki, id ng nag-upload; HINDI ang storage path)
    - History ng ticket: "Removed file (Request file): photo.png"
  Hindi na mababawi ang file mismo (walang trash/undo); ang record lang sa log ang natitira.
