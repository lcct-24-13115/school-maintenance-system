Paano gumagana
  - Sidebar > Administration > Categories (/admin/categories). Capability: manage_categories
    (Maintenance Admin lang; baguhin sa config/permissions.php).
  - Add / Edit / Hide-Show / Up-Down (reorder sa loob ng type) / Delete.
  - HIDDEN: hindi na lumalabas sa repair form at tinatanggihan din ng server kahit i-post ang ID.
    Ang lumang tickets ay nagpapakita pa rin ng category nila.
  - LOCKED: hindi pwedeng i-delete, i-rename o palitan ng type.
  - DELETE: lilipat ang mga ticket (at inventory) sa "Other" ng PAREHONG type. May 1 "Other" kada type
    (Materials / Equipment / Supplies) para hindi masira ang rule na "ang typed ticket ay gumagamit
    ng category ng type niya". Kusa itong ginagawa ng migration (kung may laman na ang categories),
    ng CategorySeeder, o sa unang delete.
  - Hindi pwedeng palitan ang type ng category na ginagamit na ng ticket.
  - Naka-log sa Audit log (action: category_changed).
  - Ang lumang "is_active" column ay hindi na ginagamit; "is_hidden" na ang pamalit (kinopya ng migration).

Rollback: php artisan migrate:rollback --step=1, tapos ibalik ang backup / git checkout -- .
