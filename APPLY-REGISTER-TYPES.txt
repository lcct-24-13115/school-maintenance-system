PAALALA / DESISYON NA KAILANGANG I-CONFIRM:
  - Ang mga type na "hindi school email" ay tumatanggap ng kahit anong email (gmail etc.) at LAGING Pending, kahit
    REQUIRE_ACCOUNT_APPROVAL=false. Kung gusto mong school email lang ang lahat: palitan ang 'school_email' => false
    ng true sa config/registration.php.
  - Ang default na napipiling tile ay Student ('default' sa config).
  - Para magtanggal ng tile, burahin ang block nito sa config/registration.php; para magdagdag, kopyahin ang isang block
    at palitan ang key. Pagkatapos: php artisan config:clear

Rollback: git checkout -- .   at   php artisan migrate:rollback --step=1   at burahin ang mga "Bago" na file.
